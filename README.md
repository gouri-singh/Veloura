

\# Veloura



Veloura is an AI-powered personal styling and fashion discovery platform designed to help users discover outfits and products based on their preferences, style, and wardrobe.



\## Features



\- User authentication

\- AI-powered personalized styling recommendations

\- Outfit and fashion product discovery

\- Product filtering and search

\- Wardrobe-based outfit matching

\- Personalized fashion suggestions

\- Responsive user interface

\- Full-stack shopping experience



\## Tech Stack



\### Frontend



\- React

\- Vite

\- Tailwind CSS

\- JavaScript



\### Backend



\- Node.js

\- Express.js

\- SQLite

\- REST APIs

\## Installation and Setup



\### Clone the repository



git clone https://github.com/gouri-singh/Veloura.git



cd Veloura



\### Setup Backend



cd backend



npm install



npm start



\### Setup Frontend



Open another terminal:



cd frontend



npm install



npm run dev



Open the local URL shown by Vite in the terminal.
